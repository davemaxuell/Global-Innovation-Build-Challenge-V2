# CPU preparation for after pretraining (2026-09-29, KST)

Done while the main run trains. No GPU use and no training; the main run was unaffected at about 395k tokens/s throughout.

## 1. Decay A/B branch support
- **`scglm_v2.train`:** can branch from a checkpoint inside another V2 random-scratch run, including a still-running one's milestone. It inherits the model, optimizer, stream cursors and RNG, with identity checks on the parent record, tokenizer, architecture, manifest, optimizer settings and checkpoint hash. Main-run behaviour is unchanged.
- **`scglm_v2.branch`:** freezes a branch config with the milestone's hash at launch and refuses to overwrite it.
- **Config:** `v2/configs/anneal_quality.json` (DCLM 25 / Edu 28 / targeted 25 / Wiki 12 / StackExchange 5 / books 5). Every source stays at or under 2.27 passes.
- **Tests:** a branch with the parent's own mix reproduces the parent's final weights bit-exactly, through the materializer as well. A new mix diverges, and a bad hash or out-of-run checkpoint is rejected.

## 2. Selection and official-reporting rehearsal
- **`scglm_v2.select_endpoint`:** development-only choice (manifest `selection` panels plus held-out benchmark-train items). It writes the frozen record `scripts/run_final_evaluation.py` requires, and the registered rule is unit-tested at its boundaries.
- **`scglm_v2.v1_vs_v2`:** the pre-registered V1-vs-V2 rule, tested against the registered reference values.
- **Rehearsal on V1's 1B model (CPU):** selection record → runner `--prepare-only` (harness commit, versions, task files, split counts) → full official protocol → `completed.json` / `summary.json` (exit 0, 17 minutes) → rule module parse check. V2's export format was checked separately on the pilot export with no scoring: provenance file, tokenizer size, EOS/prefix ID, context length, AutoModel load and 46,346,752 parameters. No official score has been computed for any V2 model. Outputs are in `v2/reports/rehearsal/`.
- **`v2/run_after_main.sh`:** chains branch → selection → official evaluation of both arms → rule → figures. It is resumable and **not armed**.
